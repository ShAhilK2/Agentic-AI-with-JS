AI => Artificial Intelligence
means => Making machines think like humans
LLM => Large Language Model
means => Large models that can understand and generate human language

# Token

Tokenization => Breaking down text into smaller units that the model can understand
Detokenization => Converting tokens back into text

LLM directly doesn't understand text, text converted to tokens

Example :
How are you?
Tokenized : ["How", "are", "you", "?"]
Exact tokenization may vary based on the model

# Context

Context => The information that the model has access to while generating a response

Include :

- Previous messages in the conversation
- User input /Current Prompt
- Document / retrieved information
- Tool results
- Instructions / System Information
- Relevant memory

# Context Window / Context Length

Context Window => The maximum amount of text that the model can process at once
Context Length => The maximum number of tokens that the model can process at once
